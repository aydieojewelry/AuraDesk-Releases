# Aura Desk

Installers and updates for **Aura Desk**, the order desk of our jewelry CAD studio (Windows).

## Install

1. Open the [latest release](https://github.com/AydieoJewelry/AuraDesk-Releases/releases/latest) and download the `.msi`.
2. Run it. If Windows shows "Windows protected your PC", click **More info → Run anyway**.
3. Open **Aura Desk** from the Start menu and sign in with Google or your email.

New accounts wait for an owner or admin to approve them.

## Updates

Aura Desk updates itself. New versions ask once; small fixes arrive silently the next time it starts. Nothing here needs to be downloaded again.

`hotfix-v…` releases hold those small fixes for the app to download. You don't need to install anything from them.
